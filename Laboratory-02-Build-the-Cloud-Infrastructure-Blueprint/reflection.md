## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. During this laboratory, I used Ubuntu through KillerCoda and was able to check the server's CPU, memory, storage, networking, and other system information using Linux commands. Linux is also useful because it can be managed directly through the terminal and is widely used for servers and cloud environments.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it keeps the information about the planned infrastructure organized. Before deployment, knowing the available resources, components, network setup, and requirements can help prevent mistakes. It also makes it easier for other members of a team to understand the plan and continue the work.
