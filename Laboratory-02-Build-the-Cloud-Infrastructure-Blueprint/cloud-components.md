# Cloud Components

## 1. Compute

The server uses an Intel Xeon E312xx processor with 1 CPU and 1 core. The compute resources are responsible for processing tasks and running applications on the server.

In a cloud environment, compute resources are important because they provide the processing power needed to run applications and services.

## 2. Storage

The server has a 20 GB virtual disk, with the main root partition using approximately 19 GB.

Storage is important because it provides a place for the operating system, applications, and data to be stored.

## 3. Networking

The server has the IP addresses `172.30.1.2` and `172.17.0.1`.

Networking allows the server to communicate with other systems and services. In a cloud environment, networking is important for allowing users, applications, and other cloud resources to communicate with each other.

## 4. Operating System

The server is running Ubuntu 24.04.4 LTS.

The operating system manages the server's hardware and provides the environment where applications and other services can run.

## Summary

The main cloud components identified from the server are compute, storage, networking, and the operating system. These components work together to provide the resources needed to run applications and services in a cloud environment.
