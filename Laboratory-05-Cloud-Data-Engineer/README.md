# Mission 5: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage server using MinIO and Docker. The goal was to create a proof-of-concept cloud storage environment for a photo-sharing application that needs to store large amounts of user-uploaded images.

The activity involved researching different types of cloud storage, deploying MinIO, accessing its web console, creating an object storage bucket, and uploading a sample file.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.
- Expand my professional GitHub Cloud Computing portfolio.
